Shared summary: Outlast the disappearing floor with layered arenas, double jumps and survival records.

All descriptions use Maze Engine's centered image-divider layout. `tnt-run-divider.svg` is the source for the 800-by-16-pixel orange divider, exported as `tnt-run-divider.png` and hosted on Hub. Spigot and Modrinth include the existing cover image in the description; BuiltByBit displays that cover automatically.

Spigot and BuiltByBit use inline-code tags for commands, permissions and PlaceholderAPI expressions to prevent smiley substitution. Prose uses Verdana, while technical text uses the platform's code font. Modrinth controls typography through its Markdown renderer.

The original screenshots and animated GIFs are hosted on Hub because direct Imgur images do not load on BuiltByBit. `tnt-run-images.json` records their original URLs, hosted URLs and SHA-256 hashes. BuiltByBit uses Spigot's working bStats image proxy for the metrics signature.

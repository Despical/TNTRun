**Arena and countdown fixes**

This update improves arena membership, inventory protection, PvP elimination and starting countdowns.

- **Arena membership:** Players can no longer join multiple arenas at the same time. Leave your current arena before joining another one.
- **Inventory protection:** Inventory dragging is now blocked while inside an arena.
- **PvP elimination:** Lethal hits from players, including player-fired projectiles, now eliminate the target into spectator mode instead of causing a normal Minecraft death.
- **Starting countdowns:** Zero-second starting countdowns now start the game at the configured player threshold. Filling an arena never extends a shorter countdown already in progress.
- **Timer validation:** Negative timer settings now produce a console warning and fall back to the corresponding defaults on startup and configuration reload.
